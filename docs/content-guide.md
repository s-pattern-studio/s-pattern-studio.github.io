# 工作室內容編輯指南

文章存在 `content/區塊/語言/檔名.md`，不用資料庫，也不用修改 HTML。開發中新增、刪除或修改 Markdown 後，頁面會重新載入；正式網站須重新建置部署才會更新。

## 分類

- `work/zh-TW/cscl.md`、`work/en/cscl.md`：每個正式網站一張卡片，整張連至 `url`。
- `records/zh-TW/donuts.md`、`records/en/donuts.md`：每張專輯一篇筆記，左側選片、右側閱讀。
- `pages/zh-TW/`、`pages/en/`：六個區塊的標題與敘述；工作室、閱讀、聯絡頁的正文已接上 Markdown。作品與唱片、地圖使用各自互動布局，其 pages 正文目前保留給未來簡介。
- `books/`、`memories/`、`studio/`、`contact/` 已保留資料夾；個別書籍與地圖地點的自訂文章尚未接入，目前請編輯 `pages` 對應頁面。地圖邊界與已造訪名單仍在地圖資料中，勿以文章代替幾何資料。
- `src/locales/`：按鈕、選單、提示等介面語言，不與文章混放。
- `public/media/`：自行提供的封面與文內圖片，可建立 albums、work 等子目錄。

中英文同一篇使用相同檔名。缺少英文時會顯示繁中版本並保留正確 lang 屬性；英文獨有文章也可發布。新增語言還需在 `src/lib/model.ts` 與 `src/locales` 註冊介面翻譯，內容讀取不需重寫。

## 作品模板

```md
---
title: 作品名稱
url: https://your-live-site.example/
order: 2
draft: true
---

作品的一段簡介，建議 40–100 字。可用 **粗體** 強調參與角色。
```

複製到 work 對應語言資料夾，填好正式網址後把 `draft` 改為 `false`，或刪除此欄。較小的 order 排前面。draft 文章不會送進前端。

封面優先順序：frontmatter 的 `cover` → 網站 `og:image` → 工作室原創預設圖形。`cover` 可填 `https://...` 或 `/media/work/my-project.webp`。分享 metadata 在開發伺服器／建置時抓取，不在訪客瀏覽器跨站抓 HTML；4.5 秒逾時、抓取失敗或缺少 metadata 都會退回預設封面。開發期間網址結果暫存，重啟開發伺服器可重新抓取。圖片本身直接載入來源網址，失效時也有預設封面；若對方禁止外連，請自行放入有使用權的圖片。

整張作品卡片是連結，內文中的連結只顯示文字，避免巢狀連結。卡片描述最多顯示三行，長篇案例請放在作品網站。

## 專輯模板

```md
---
title: 專輯名稱
artist: 音樂人
order: 3
accent: '#aa7049'
draft: true
---

## 第一次聽到它

在這裡寫自己的故事。

> 想留下的一個念頭。

## 喜歡的片段

- 第一個片段
- 第二個片段

[前往 YouTube](https://www.youtube.com/)
```

可加 `cover` 放唱片標籤圖、`url` 放聆聽連結。正文支援標題、段落、粗體、清單、引用、程式碼、表格、圖片與連結。原始 HTML 不會執行；影片以外部連結呈現。這是 Markdown 發布流程，不是線上 HackMD 編輯器，也尚無 HackMD 的協作、數學或圖表語法。

專輯請以同一檔名對應翻譯；照片用 `![圖片描述](/media/albums/photo.webp)`。圖片會延遲載入。筆記在桌面右側獨立滾動，滑鼠在左側才切換專輯；手機上方滑動選片，下方閱讀。

## 檢查

執行 `npm run build` 會檢查必填標題、網址、藝人、排序、色碼與 draft 格式，錯誤會附檔案路徑。發布前確認兩種語言與手機畫面，再部署 `dist/`。CSCL 目前只放「已正式上線的網頁作品」；請補上自己的角色、方法與成果，避免把未確認資訊當成案例事實。

作品版面：1440px 起為三欄、761–1439px 為兩欄、手機一欄。一次滾輪手勢（包含觸控板慣性）只前進或後退一張，也可使用方向按鈕、鍵盤方向鍵或手機左右滑動。
