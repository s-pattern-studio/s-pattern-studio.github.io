## 最終確認：真正的 3D 鏡頭推近

修正首幀閃跳：在 useFrame 更新鏡頭前，原子化判斷目標切換、擷取當前鏡位並歸零進度。移除被動 effect 初始化與自動回全景重設，避免新目標讀取上一段的完成進度。Canvas 初始攝影機設定保持固定參照。

物件轉場依序為：3D 攝影機先從全景轉向物件，再移動到中距離構圖、穩定片刻後最後推近（分段共約 1.7 秒）→抵達物件近距離鏡位→輕量表面由此時的投影範圍擴滿畫面（420ms）→掛載 2D 詳細內容。關閉依相反順序縮回物件（320ms）再退回全景。攝影機確實在 Three.js 空間移動；不能用只放大平面表面或淡入淡出替代。六個近距離鏡位均對準對應表面中心，另有各自避開家具的中距離構圖；若上一次退回尚未完成，中途改選會從當前鏡位接續，不會插入回全景重設。2D 表面以透明度銜接實體物件，避免突然蓋上色塊。书櫃與唱片櫃的重複物件使用 InstancedMesh 合併繪製，減少推近時的繪製次數。先前維持全景的平面放大方案已取代。

漢堡選單形變、雙向收合、統一 StudioSelect 選單及已移除的底部分區列維持不變。

## 最新互動共識：恢復物件放大過場

保留 3D 物件位置到全螢幕 2D 的放大、以及關閉時縮回物件的雙向過場。最新實作由 Three.js 計算物件在全景中的投影範圍，獨立純色表面以 transform 動畫放大 560ms／縮回 420ms；詳細地圖、唱片與文字在放大完成後才掛載，不隨動畫縮放。場景維持全景快取，避免同時重新繪製 3D 與重型 2D。減少動態偏好仍跳過動畫。先前 180ms 淡入淡出的方案已被取代，底部分區列仍移除。

漢堡三線圖示與關閉符號之間有雙向形變，選單有展開／收合動畫、外部點擊與 Escape 收起。語言、場景光線、地圖地區共用 StudioSelect 深色暖金樣式，支援鍵盤；地圖選單另有搜尋。

## 最新修正：地圖與轉場

以下規則取代較早的鏡頭靠近／表面放大描述：點選物件後直接以 180ms 同色系淡入淡出顯示內容，3D 場景保持全景並在面板開啟時停止渲染。取消整頁縮放與分區鏡頭移動；底部分區列已移除，保留物件熱點與右上導覽。關閉後呈現原全景。

牆面 SVG 指定 1440 × 960 尺寸供 WebGL 正確建立貼圖。詳細地圖以容器實際長寬比調整 viewBox，世界／臺灣範圍、縮放上下限與拖曳皆經同一邊界函式限制；臺灣範圍包含資料中的離島。新增拖曳、連續縮放、手機比例及貼圖尺寸回歸測試。

# S. Pattern Studio

第二階段：全螢幕 3D 安全屋與內容架構雛形。React + TypeScript + Tailwind CSS + React Three Fiber / Three.js。

## 本機執行

Node.js 22.16+（目前測試環境），npm。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

## 目前功能

- 由程式幾何建立的 3D Loft：唱片櫃、獨立書櫃、作品桌、海報牆、城市地圖。
- 房間本身就是首頁：全螢幕室內透視鏡頭，不再使用左右分欄或房間縮圖。
- 物件標記依世界座標投影，跟隨鏡頭移動；點擊後靠近該區域，700ms 後切換全螢幕 2D 內容。可透過底部導覽只切換鏡位，或右上目錄直接選擇內容。
- 原生 dialog 支援鍵盤、Escape、焦點鎖定及關閉後返回焦點。關閉後保留剛剛的房間鏡位，點「房間全景」回到起點。
- 繁體中文、英文，語言保留在 URL 與本機設定。Hash 路由支援瀏覽器前進／返回、重新整理與 GitHub Pages 子路徑。
- 自動跟隨訪客本地時間，或手動切換清晨、白天、黃昏、夜間；設定會記住。
- demand rendering、最高 1.5 DPR、單張快取 1024px 陰影圖、懶載入 Three.js；分頁隱藏或開啟面板時停止渲染。材質紋理由程式產生。
- 靜態瀏覽開關；WebGL 不可用或減少動態偏好時提供概念圖與全部 HTML 入口。

## 檔案分工

- `src/App.tsx`：首頁、內容面板、路由、互動。
- `src/Scene.tsx`：空間幾何、光線、可點擊區域、程序海報。
- `src/lib/views.ts`：安全屋鏡位與物件熱點座標。
- `src/locales/`：獨立介面字典，兩種語言由 TypeScript 檢查同一結構。
- `src/lib/model.ts`：locale/section registry、內容翻譯回退、城市故事、聯絡設定、時間光線。
- `public/concept.jpg`：前一階段 AI 生成的概念參考圖壓縮副本；不是最終 3D 場景。
- `docs/design-direction.md`：設計共識、階段範圍、待提供內容。

新增語言：擴充 `locales` 與 `localeConfig` registry、加入與 `Messages` 同結構的字典、註冊於 `src/locales/index.ts`。語言選單自動列出 registry 中的語言。故事可使用 `Localized<T>`；缺少翻譯時回退至繁中。

## 物件轉場與旅行地圖（2026-10-04）

- 底部導覽直接開啟物件內容。鏡頭完成移動才回報物件的投影範圍，2D 表面再由該範圍展開；關閉時收回表面，再回房間全景。保留場景、不再靠固定等待時間切斷鏡頭。標籤位置只寫入 transform，避免每幀讀取版面尺寸。
- `src/lib/surfaces.ts` 統一六種物件表面顏色及座標。螢幕採不受燈光色調映射影響的同色材質。其他物件沿用木質、紙本／海報、地圖、名片的配色。
- `src/components/RecordsPanel.tsx`：桌面左側滾輪／方向鍵／點選章節，右側同步內容；手機使用上下編排、滑動及按鈕。唱片靈感與舞蹈章節有各自的分類，封面為原創示意。
- `src/components/TravelAtlas.tsx`：242 個國家與地區、10 座城市行政邊界、臺灣 22 縣市；支援縮放、拖曳、選單與足跡列表。臺灣已走訪：屏東、高雄、花蓮、臺中、臺北、雲林、嘉義縣、嘉義市、臺南、南投。未指定家鄉，因此沒有額外標記家鄉所在地。
- `scripts/build-maps.mjs` 將本地 GeoJSON 快照投影為 SVG 路徑。只在進入地圖時讀取 `world.json` / `regions.json`，不在訪客端呼叫地理服務。新增城市需補入實際行政邊界，並非全球每座城市都已收錄。
